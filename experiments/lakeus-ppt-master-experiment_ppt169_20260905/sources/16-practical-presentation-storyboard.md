# Practical presentation storyboard

**Build record, 5 September 2026.** 23-slide sequence for the revised [60-minute run of show](02-one-hour-run-of-show.md). The [updated PowerPoint](../output/lakeus-devaus-2026-practical.pptx) follows this sequence. The visual descriptions below retain the original intent; the production differences are recorded here. Slide numbers refer to the new sequence.

Production differences: the learning chart uses editable PowerPoint bars and labels because Excel was unavailable. The address walkthrough is an explicitly illustrative teaching sequence with editable code and proposed checks; no demo browser capture, regression run, or released PR is claimed. Project context, tools, and parallel work use short comparison panels. No reveal animations were added. All 23 slides have Finnish notes and were inspected in native slideshow view; structural, layout, and import validation passed.

The practical example is a teaching scenario. Use real captured evidence from a prepared demo when producing it; until then, label any explanatory mockup as illustrative. Do not attribute the scenario to the speaker's personal work.
